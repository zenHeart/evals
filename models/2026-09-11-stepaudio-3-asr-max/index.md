# StepAudio 3 ASR

发布日期取本仓通道指引「StepAudio 3 取 arXiv 2609.12945 = 2026-09-11」的家族锚点——本页本身未印发布日，详见账本 release notes。

StepAudio 3 ASR Max 是阶跃星辰迄今规模最大的 ASR 模型，以大语言模型为语义底座，把高精度声学建模与大语言模型的上下文理解、知识储备和推理能力融合，让语音识别从「辨认声音」走向「理解语境」。官方模型页明文给出 4 组本模型绝对值与 3 组竞品对照值，全部为散文口径（非图表）。

## 官方明文绝对分值（散文）

| 评测 | 分数 | 备注 |
| --- | --- | --- |
| 上下文推理（厂商自建集） | 0.57% | 错误率，越低越好；官方原文：「上下文推理：错误率为 0.57%，相比 StepAudio 2.5 ASR 的 1.59% 降低 64.2%；相比豆包 ASR 2.0 的 1.00% 降低 43.0%。」 |
| 垂类专名（厂商自建集） | 3.81% | 错误率，越低越好；覆盖体育、医药、化工、汽车、法律、金融、编程开发等 20+ 领域的平均错误率 |
| 无语音测试（厂商自建集） | 99% | 准确率，越高越好；用于减少环境声、背景音乐与静音片段引发的错误转写 |
| AISHELL-6 悄悄话 | 3.97% | CER（字符错误率），公开集子集口径；官方原文：「AISHELL-6 悄悄话测试 CER 为 3.97%，优于上一代的 5.36%」 |

## 不建行的相对降幅（非绝对分值）

官方另印一组「相对上一代 / 相对豆包 ASR 2.0 的**降低百分比**」：中文通用 9.3%、英文 25.0%、方言 22.3%、垂类 42.1%、中英混说 27.9%；相对豆包 ASR 2.0 的中文通用 18.6%、英文 60.4%、重口音 23.3%、长音频 40.3%、上下文推理 43.0%。**这些是相对改善幅度，不是基准上的绝对分值**，按账本口径不建行，只在本索引与账本 notes 中留痕。
