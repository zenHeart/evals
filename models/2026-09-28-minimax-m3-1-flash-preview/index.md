# MiniMax-M3.1-Flash-Preview

MiniMax-M3.1-Flash-Preview 是 MiniMax 推出的新一代混合专家（MoE）思考模型，总参数 428B，激活参数约 23B，原生支持 1,000,000 tokens（1M）超长上下文与原生多模态（文本、图片、视频输入）。模型默认开启深度思考（always-on thinking），提供 Low 到 Max 五档思考深度，并通过独立 `reasoning_content` 字段输出思考过程。

官方产品落地页（`https://agent.minimax.cn/tools/m3-1-flash-preview` 与 `https://agent.minimax.io/tools/m3-1-flash-preview`）展示了相比 M3 在上下文、思考模式与视觉分辨率方面的对比，并提供了四个实战场景案例（Flowdesk 工单故障排查、贵州茅台财务 DCF 估值、复杂图像差异分析、3D 流体模拟网页应用），但未披露离散标准基准打分表，依规范证据状态记为 `pending`。
