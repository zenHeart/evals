# 11. 行业垂直评测：医疗、法律、金融、电商

> **如果只读一节**：MedQA = 医生执照考试，LegalBench = 律师工作，FinBen = 金融分析，EcomInstruct = 电商客服。**专业领域评估决定"AI 能不能用"**。

## 11.1 本章目标

读完后你能：

- 知道 4 大垂直行业的核心评测
- 知道每个评测的数据来源和评估方式
- 知道 AI 在专业领域的真实水平
- 知道为什么"通用评测"不够

**前置知识**：第 5-8 章基础。

## 11.2 为什么需要垂直评测

**通用评测的局限**

```
MMLU 90% ≠ 能当医生
HumanEval 95% ≠ 能写法律合同
```

通用评测测的是"广度"，但**专业应用需要"深度"**。

**垂直评测的核心问题**

| 行业 | 关键问题 |
|---|---|
| 医疗 | "这个症状应该诊断什么病？" |
| 法律 | "这份合同有什么风险？" |
| 金融 | "这个公司值不值得投资？" |
| 电商 | "客户投诉怎么处理？" |

## 11.3 医疗评测

**MedQA（USMLE 风格）**

> **测 AI 能否通过美国医生执照考试**。

- 数据来源：USMLE（美国医学执照考试）真题
- 规模：~60,000 道多选题
- 涵盖：内科、外科、儿科、妇产科、精神科
- 评估：多选 accuracy

**当前 SOTA**：

| 模型 | MedQA |
|---|---|
| GPT-4o | 88% |
| Claude 3.5 Sonnet | 90% |
| Med-PaLM 2（Google 医疗专用） | 86.5% |
| 人类医生通过线 | 60% |

**结论**：AI 已在 MedQA 上"通过"USMLE 水平考试。

**PubMedQA**

> **测 AI 理解医学文献的能力**。

- 数据来源：PubMed 摘要
- 任务：判断论文结论是否支持某假设
- 规模：1,000 个专家标注样本
- 评估：accuracy

**当前 SOTA**：85-90%。

**医疗评测的局限**

⚠️ **AI 通过考试 ≠ 能当医生**
- 考试 vs 真实临床推理
- 风险极高（错一个建议可能致命）
- 需要 HIPAA 合规、数据隐私

## 11.4 法律评测

**LegalBench**

> **测 AI 律师工作能力**。来源：实际法律任务。

- 162 个任务，覆盖 6 大类：
  - 合同审查
  - 法规检索
  - 案例分析
  - 法律意见起草
  - 合规审计
  - 法律推理
- 数据来源：实际律所任务（脱敏后）

**任务示例**：

```
[任务] "审查这份 SaaS 合同，找出 3 个对客户不利的条款"
[输出] "1. 第 5.2 条自动续约未提供 30 天通知期..."
```

**当前 SOTA**：

| 模型 | 任务通过率 |
|---|---|
| GPT-4o | 65% |
| Claude 3.5 Sonnet | 70% |
| 律师（人类基线） | 85% |

**MMLU Law**

> 法律子集（基于 MMLU 框架）

- 涵盖：宪法、刑法、合同法、侵权法、知识产权
- 规模：~1500 道多选题
- 当前 SOTA：85%+

**法律评测的伦理问题**

⚠️ **AI 律师有严格合规要求**
- 美国：Unauthorized Practice of Law (UPL) 法律
- 中国：《律师法》
- 必须明确告诉用户"我不是律师"
- 不能替代律师出具法律意见

## 11.5 金融评测

**FinBen**

> **测 AI 金融分析能力**。综合性金融基准。

涵盖任务：

| 任务 | 描述 |
|---|---|
| 财报分析 | "分析这份年报的关键风险" |
| 投资建议 | "基于这些数据，该买还是卖？" |
| 风险评估 | "这份贷款的违约概率？" |
| 监管合规 | "这笔交易符合 SEC 规定吗？" |
| 量化分析 | "回测这个交易策略" |

**当前 SOTA**：

| 模型 | FinBen 总分 |
|---|---|
| GPT-4o | 70% |
| Claude 3.5 Sonnet | 75% |
| 金融分析师 | 90% |

**FinEval**

> **中文金融评测**。

- 来源：中国金融考试（CFA、证券从业资格、基金从业资格）+ 实际金融任务
- 规模：8,000+ 题
- 任务：知识题 + 案例分析 + 投研报告

**当前 SOTA**：

| 模型 | FinEval |
|---|---|
| Qwen2.5-72B | 80% |
| DeepSeek-V3 | 78% |
| GPT-4o | 75% |

**金融评测的局限**

⚠️ **金融决策风险极高**
- 错误可能导致巨额损失
- 需要 CFA 持证人监管
- 涉及内幕信息、合规
- **永远不能让 AI 独立做投资决策**

## 11.6 电商评测

**EcomInstruct**

> **测 AI 电商场景能力**。

任务类型：

| 任务 | 示例 |
|---|---|
| 商品描述生成 | "为这款智能手表写 5 个不同风格的文案" |
| 客服对话 | "客户说商品有质量问题" |
| 评论分析 | "分析这 1000 条评论的情感和痛点" |
| 推荐解释 | "为什么推荐这个商品给该用户" |
| 价格策略 | "基于历史销售数据，建议定价" |

**当前 SOTA**：

| 模型 | 任务通过率 |
|---|---|
| GPT-4o | 80% |
| Claude 3.5 Sonnet | 82% |
| 电商专家 | 90% |

**电商评测的隐性挑战**

- 商品知识更新快
- 多语言（中英小语种）
- 文化差异
- 促销规则复杂

## 11.7 其他垂直评测

**CodeUltraFeedback**

> **代码生成的高质量反馈**。给代码打分的多维度。

- 维度：功能正确性、风格、安全、性能、可维护性
- 用 LLM-as-Judge 给多维度评分
- 训练 RLHF 用

**TravelBench**

> **测 AI 旅行规划能力**。

- 真实旅行场景
- 多轮规划
- 涉及：航班、酒店、行程

**Med-PaLM**

> **Google 医疗专用模型评测**。

- MedQA + USMLE + 实际临床问题
- 医学知识深度

## 11.8 行业评测的"不可替代"准则

| 行业 | 关键约束 | AI 角色 |
|---|---|---|
| 医疗 | HIPAA、患者安全 | 辅助（不替代医生） |
| 法律 | 律师法、UPL | 辅助（不替代律师） |
| 金融 | SEC、合规、风险 | 辅助（不替代交易员） |
| 电商 | 客户体验、品牌 | 协作（部分自动化） |
| 教育 | 因材施教、安全 | 辅助（不替代教师） |

**金科玉律**：高风险行业 = AI 辅助 + 人类把关。

## 11.9 如何为你的垂直行业评测

```
1. 收集行业真题（考试、案例、文档）
2. 标注真实任务（脱敏后）
3. 设计评估指标
4. 与领域专家建立评分 rubric
5. 跑评估 + 报告
```

详见第 22-23 章。

## 11.10 ⚠️ 5 个常见错误

1. **通用评测分数高 = 专业能用** — 错。MedQA 90% ≠ 能当医生。
2. **忽视合规和伦理** — 法律/医疗 AI 必须有"我不是专业人士"的免责声明。
3. **数据隐私** — 用真实患者/客户数据训练 = 违法。
4. **过度依赖** — AI 给建议，人类必须决策。
5. **没有领域专家参与评估** — 让律师/医生参与设计评估。
